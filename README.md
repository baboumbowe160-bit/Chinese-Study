# Chinese Study

Offline app for practising Chinese character stroke order (HSK 1 words, class words and your own words).

Live: https://baboumbowe160-bit.github.io/chinese-study/

Stroke animations: Hanzi Writer (MIT). Stroke data: Make Me a Hanzi (Arphic Public License).

Audio: native-speaker recordings from audio-cmn (https://github.com/hugolpz/audio-cmn) — HSK words by Yue Tan and syllables by Chen Wang, CC BY-SA. Volume-normalised and joined for this app.

Basics tab: radical list from the Unicode Kangxi Radicals block; meanings, pinyin and origin notes partly from the Make Me a Hanzi dictionary (LGPL, https://github.com/skishore/makemeahanzi); beginner explanations written for this app.
